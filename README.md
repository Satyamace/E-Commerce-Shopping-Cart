# 🛒 E-Commerce Shopping Cart

A responsive shopping cart application built with HTML, CSS, and JavaScript. It provides an interactive shopping experience with dynamic cart updates, quantity management, and persistent storage.

## 🚀 Live Demo

* **Live Website:** [View Shopping Cart](https://satyamace.github.io/E-Commerce-Shopping-Cart/)
* **GitHub Repository:** [View Source Code](https://github.com/Satyamace/E-Commerce-Shopping-Cart)

## ✨ Features

* 🛍️ Browse products
* ➕ Add products to the cart
* 🔢 Increase or decrease product quantities
* 🗑️ Remove items from the cart
* 💰 Dynamic total price calculation
* 💾 Persist cart data using localStorage
* 📱 Responsive design for mobile and desktop
* ⚡ Interactive UI with event delegation

## 🛠️ Technologies Used

| Technology   | Purpose                                 |

| HTML5        | Application structure                   |

| JavaScript   | Cart functionality and DOM manipulation |
| localStorage | Persistent cart storage                 |

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Satyamace/E-Commerce-Shopping-Cart.git
```

### 2. Navigate to the project directory

```bash
cd E-Commerce-Shopping-Cart
```

### 3. Run the application

Open `index.html` in your browser or use the VS Code Live Server extension.
